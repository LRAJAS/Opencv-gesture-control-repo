# 🖐️ OpenCV Gesture Control & Recognition using MediaPipe

Welcome to the **OpenCV Gesture Control** repository!  
This project contains a collection of real-time gesture-based computer vision mini-projects built with **OpenCV**, **MediaPipe**, and **Python**. It covers everything from basic hand tracking to AI-powered applications like virtual mouse control, volume control, AI painting, and facial recognition.

---

## 📌 Project Highlights

| Feature                   | Description                                                       |
|--------------------------|-------------------------------------------------------------------|
| ✋ Hand Tracking          | Real-time hand landmark detection using MediaPipe                 |
| 🎮 Virtual Mouse          | Control your mouse using hand gestures                            |
| 🔊 Volume Control        | Adjust system volume using hand distance                          |
| 🎨 AI Painter            | Paint in a canvas using finger as a virtual brush                 |
| 🧠 Face Recognition      | Real-time face recognition using OpenCV and CNN                   |
| 📷 Pose Recording        | Save pose landmark data from webcam feed for training             |
| 🎯 Project Launcher      | Easily launch all sub-projects from a central `main.py` file       |
